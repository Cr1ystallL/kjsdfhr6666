# MacvCoin ($MACV) — Telegram Mini App & Bot Ecosystem

Полноценное независимое игровое Telegram Mini App приложение формата Tap-to-Earn с прицелом на запуск реального CryptoCoin ($MACV) через 1 месяц. Проект полностью изолирован и не имеет никаких связей с другими проектами.

## Структура проекта
- `bot/` — Telegram-бот на Python 3 (`aiogram 3.x`).
- `server/` — Высокопроизводительный Node.js Express бэкенд с REST API, транзакционной базой данных и авто-деплоем.
- `webapp/` — Telegram Mini App (React + TypeScript + Vite + Tailwind CSS + Lucide Icons).
- `setup-server.sh` — Скрипт первоначальной настройки VPS за 1 команду.
- `deploy.sh` — Скрипт сборки и обновления.
- `auto-sync.sh` — Фоновый демон авто-деплоя при пуше в Git.
- `DEPLOYMENT_GUIDE.md` — Подробная инструкция по настройке совместной работы с другом через Git и автообновлению сервера.

## Экраны приложения:
1. **Майнинг (Главный экран)**: 3D монета MacvCoin с мультитач-кликером, физикой наклона, всплывающими очками, регенерацией энергии и бесплатным ежедневным бустом "Полная энергия" (3/3).
2. **Прокачка (Улучшения)**: Мульти-тап, Вместимость энергии, Скорость зарядки + 6 видов пассивных майнинг-узлов (Крипто-узел, Пул ликвидности, Нейро-трейдер, Серверный кластер, Мастернода, TON Стейкинг).
3. **Задания**: Социальные квесты, подписка на каналы и чаты, реферальные достижения с проверкой и мгновенным начислением наград.
4. **Бонусы**: 7-дневный календарь стрика (от 1 000 до 150 000 $MACV) + Сундук Удачи (раз в 4 часа с дропом до 15 000 $MACV).
5. **Профиль**: Лига игрока, статистика, реферальная ссылка (10% комиссия) и привязка некостодиального Web3 TON кошелька для будущего аирдропа.
6. **О монете ($MACV)**: Дорожная карта на 4 этапа, токеномика проекта и формула начисления Airdrop перед листингом на DEX/CEX.
